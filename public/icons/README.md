# PWA Icons

This directory contains icons for the Progressive Web App manifest.

## Required Icons

- `icon-192.png` - 192x192px icon (required for PWA)
- `icon-512.png` - 512x512px icon (required for PWA)

## Temporary Placeholder

A placeholder SVG has been created. To generate proper PNG icons:

1. Create or obtain a high-quality 512x512px PNG logo
2. Use an image editor or online tool to resize to 192x192px
3. Replace the placeholder SVG with actual PNG files

## Design Guidelines

- Use simple, recognizable designs (Colombia flag, map outline, etc.)
- Ensure good contrast for visibility
- Consider maskable icon safe zones (80px padding from edges for 512px icon)
- Use the app's primary color (#3b82f6) for brand consistency
