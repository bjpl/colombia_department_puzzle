### Test Patterns Used

**1. Arrange-Act-Assert**
```typescript
test('should place department correctly', () => {
  // Arrange
  const { getByText, getByRole } = render(<GameContainer />);

  // Act
  const dept = getByText('Antioquia');
  fireEvent.dragStart(dept);

  // Assert
  expect(getByRole('status')).toHaveTextContent('Correcto');
});
```

**2. User-Centric Testing**
```typescript
test('keyboard navigation works', async () => {
  render(<GameContainer />);
  const user = userEvent.setup();

  // Simulate real user interaction
  await user.tab();
  await user.keyboard('{ArrowRight}');
  await user.keyboard('{Enter}');

  // Verify outcome user would see
  expect(screen.getByRole('alert')).toBeInTheDocument();
});
```

**3. Accessibility Testing**
```typescript
test('has proper ARIA labels', () => {
  const { container } = render(<GameHeader />);

  expect(container.querySelector('[aria-label]')).toBeTruthy();
  expect(screen.getByRole('navigation')).toBeInTheDocument();
});
```
