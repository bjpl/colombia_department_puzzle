## Architecture Notes

### Provider Wrapping
The `renderWithProviders()` function automatically wraps components with:
- **MemoryRouter** - For route-dependent components
- **Future-ready** - Easily extend with ThemeProvider, StateProvider, etc.

### Extensibility
The infrastructure is designed for easy extension:
```typescript
// Add new providers to AllProviders component
function AllProviders({ children, options }) {
  return (
    <MemoryRouter initialEntries={[options.route]}>
      <ThemeProvider theme={options.theme}>
        <GameStateProvider initialState={options.initialState}>
          {children}
        </GameStateProvider>
      </ThemeProvider>
    </MemoryRouter>
  );
}
```
