# PWA Screenshots

This directory contains screenshots for the Progressive Web App manifest.

## Required Screenshots

- `mobile.png` - 750x1334px (narrow form factor) - iPhone 8 dimensions

## Guidelines

- Take screenshots of the actual game in mobile viewport
- Ensure gameplay is visible and attractive
- Use consistent theme and branding
- Remove any personal data or debugging info

## Temporary Status

Screenshots should be generated after the UI is complete. For now, the manifest
references a placeholder path that can be updated later.
